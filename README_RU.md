# Аккредитации и Другие Бумаги для Бизнеса

### Инструмент для быстрого и лёгкого добавления текста на изображения по типу сертификатов в больших количества

# Особенности:

* Быстрый импорт изображений и документов
* Обширная поддержка форматов изображений (.png, .jpeg., .bmp and others) и документов (.xlsx, .xls, .ods, .csv и другие)
* Базовые средства кастомизации текста (центрирование, цвет, и т.д.)
* Интуитивный интерфейс

# Как использовать:

1. Выберите шаблон вашего документа.
2. Выберите таблицу из которой будут доставаться добавления (должна быть незащищённой).
3. Выберите любое из добавлений, сгенерированных инструментом (первая строка первой страницы вашего документа) и нажмите "Добавить поле на холст".
4. Перетащите поле на изображение (оно автоматически следует за вашей мышью).
5. Кликните когда вы довольны положением поля.
6. Повторяйте шаги 3-5 пока все поля, которые вам нужны на законченном документе, не будут вставлены.
7. Нажмите кнопку "Сохранить изображения", выберите расположение сгенерированных изображений.
8. При сохранении, данные, соответствующие каждому полю будут вытащены из вашего документа и будут применены к законченному изображению в позициях, в которые вы их перетащили.
9. Наслаждайтесь созданными аккредитациями и другими бумагами для бизнеса. :)

Полная инструкция к инструменту также может быть найдена внутри него, доступная при запуске программы. 

# Инструкция по сборке:

Если вы хотите сами собрать проект, сделайте следующее:

1. Клонируйте проект используя Git:
```
git clone https://github.com/CyberBro9/aobp.git
cd aobp
```
2. Установите зависимости проекта:
```
pip install -r requirements.txt
```
3. Установите pyinstaller (не спрашивайте почему мы используем это вместо pyside-deploy):
```
pip install pyinstaller
```
4. Скомпилируйте программу:
```
pyinstaller --onefile --icon=Assets/aobp.ico --hiddenimport pyexcel --hiddenimport pyexcel_io --hiddenimport pyexcel_xls --hiddenimport pyexcel_xlsx --hiddenimport pyexcel_ods --hiddenimport xlrd --hiddenimport xlwt main.py
```
Вы также можете найти команду для компиляции в buildCommand.txt.
5. Добавте папку Assets внутри папки dist (она появится при завершении компиляции).
6. Теперь программа должна запуститься.
