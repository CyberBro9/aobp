# Accreditations (and) Other Business Papers

### A tool for quickly and easily putting text on images such as certificates in large amounts

# Features:

* Fast image and document import
* Vast support for different image (.png, .jpeg., .bmp and others) and document (.xlsx, .xls, .ods, .csv and others) formats
* Basic text customization features (text centering, text color, etc.)
* Intuitive UI

# How to use:

1. Select a document template.
2. Select a document to pull selections from (must be unprotected).
3. Select any of the selections generated by the tool (the first row of your document's first sheet) and press "Add selection to image".
4. Drag the field onto the image (it automatically follows your mouse).
5. Click when you are satisfied with the field's position.
6. Repeat steps 3-5 until all fields that you need on the final document are pasted in.
7. Press the "Save images" button, select the generated images' destination.
8. While saving, data corresponding to every field will be pulled from your document and applied to the final image in the positions you put them on.
9. Enjoy your created accreditations and other business papers. :)

The complete tutorial for the tool can also be found in it, accessible on program launch.

# Build instructions:

If you want to build the project from scratch, do the following:

1. Clone the project using Git:
```
git clone https://github.com/CyberBro9/aobp.git
cd aobp
```
2. Install the project dependencies:
```
pip install -r requirements.txt
```
3. Install pyinstaller (do not ask why we use that instead of pyside-deploy):
```
pip install pyinstaller
```
4. Compile the program:
```
pyinstaller --onefile --icon=Assets/aobp.ico --hiddenimport pyexcel --hiddenimport pyexcel_io --hiddenimport pyexcel_xls --hiddenimport pyexcel_xlsx --hiddenimport pyexcel_ods --hiddenimport xlrd --hiddenimport xlwt main.py
```
You can also find the compilation command in buildCommand.txt.
5. Add the Assets folder inside the dist folder (it will appear upon compilation finish).
6. The program should now run.
